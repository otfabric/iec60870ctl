# Releases

Release notes of iec101ctl, iec102ctl, iec103ctl and iec104ctl, newest first. A section's
heading is exactly the tag it belongs to: `## vX.Y.Z` when the four tools are released
together with one version, `## <tool>/vX.Y.Z` (for example `## iec104ctl/v1.0.0`) when a
tool is released on its own; the section ends with a line `---`. The Release workflow
publishes the section as the release notes and stops without it ([docs/RELEASING.md](docs/RELEASING.md)).

Nothing has been released from this repository yet. The releases of iec104ctl from its
own repository are in [docs/iec104ctl/HISTORY.md](docs/iec104ctl/HISTORY.md).
